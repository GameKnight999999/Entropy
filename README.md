# Измерение информации в сообщении 🎯

Обучающее веб-приложение для изучения темы **"Измерение информационного объёма сообщения"** на основе формулы `V = N · log₂(I)`.

---

## Инструменты и версии

- **Язык**: C# типизированный (strongly typed)
- **Фреймворк**: Blazor Server (.NET 10.0)
- **ASP.NET Core** для веб-серверной части

### Среда сборки

```bash
dotnet build ./Entropy.csproj
```

---

## Архитектура приложения

### Части приложения

| Компонент | Назначение | Локация в коде |
|-----------|-------------|-----------------|
| **App.razor** | Главная страница с формулой и примером | `/Home/stepa/c#/Entropy/App.razor` |
| **Pages/** | Страницы (проект) `Example.razor` не создан пока что для демо-размера алфавита до 32 символов | В корневой папке или в папке Pages если будет добавлен отдельный файл с примером расчёта |
| **Models.cs** | Модель данных, статические константы и формулы (I=4, N=8) | `/Home/stepa/c#/Entropy/Models.cs` |
| **Program.cs** | Настройка веб-сервера и роутинг | В корне `./Homestpa/c#/Entropy` |

### Состояние приложения

- Хранится в памяти (in-memory). Сбрасывается при перезапуске сервера.
- Изменение **I** пересчитывает **V = N · K = N · log₂(I)** и обновляет визуализацию символов, их коды и объём сообщения.

### Движение данных (action)

1. Пользователь выбирает **мощность алфавита I**.
2. Расчёт `K = log₂(I)` → обновляется на экране.
3. Вывод сообщения (карточки символов + битовые коды).
4. Подстановка в формулу → показанный объём V (округление до байта).

### Обработка ошибок

- **Недопустимый ввод** — если I не степень двойки, вывод сообщение об ошибке.
- **Закрытие соединения** — перезагрузка страницы.

---

## Проверка и сдача

- 5+ проверок сделаны:
  - Обычный случай (I = 4, N = 8)
  - Особый случай I = 8 → пересчёт K = 3 бит на символ
  - Неправильный ввод → отображает ошибки
  - Изменение конфигурации → обновление расчётов
  - Перезапуск сервера → сброс состояния
