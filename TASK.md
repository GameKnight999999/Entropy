## 🎯 Цель
Обучение формуле `V = N · log₂(I)` с интерактивной визуализацией и практическими задачами.

---

## 1️⃣ Тип задач

**Выбор алфавита:** не произвольная мощность `I`, а готовый список:
- «Русский» (≈30-40 символов)
- «Английский» (≈50 символов)  
- «ASCII без управляющих» (128 символов)

**Пользовательские входные данные:**
1. **Алфавит из списка** — выбирается один из готовых вариантов
2. **Бит на символ (`k_bits`)** — пользователь вводит число:
   - Если `k_bits ≥ log₂(I)` → используем по выбору пользователя
   - Если `k_bits < log₂(I)` → ошибка, недостаточно бит

3. **Длина сообщения** — пользователь вводит `N` (проверка 5 ≤ N ≤ 256)

**Вычисление объёма:**
- `k = log₂(I)` — минимально необходимое бита на символ для полного кодирования выбранного алфавита
- `V_raw = N × k_bits` — расчёт пользователем, где `k_bits` от пользователя
- Система проверяет ответ пользователя или подсчитывает сама и сравнивает

**Отображение:**
```
Алфавит выбран: «@AlphabetName» (I = @Alphabet_Size символов)
log₂(@Alphabet_Size) = @(Math.Round(Math.Log(Alphabet_Size)/Math.Log(2), 1)) бит на символ
Пользователь выбрал k_bits = @(UserKBits) бит/символ

Проверка:
k_minimum = log₂(@Alphabet_Size) = @(Math.Round(Math.Log(Alphabet_Size)/Math.Log(2), 1)) бит
Если @(UserKBits < Math.Round(Math.Log(Alphabet_Size)/Math.Log(2), 0)) → **Ошибка: недостаточно бит!**

Расчёт объёма:
N = @UserMessageLength символов
V_raw = N × k_bits = @UserMessageLength × @UserKBits = @(UserMessageLength * UserKBits) бит
V_bytes = ceil(V_raw / 8) = @(Math.Ceiling(UserMessageLength * (Math.Log(Alphabet_Size)/Math.Log(2)) / 8.0)) байт
```

  - Таблица двоичных кодов для всех символов этого алфавита (если нужно)

### Группы бита в сообщении
**Отображение:**
- При заданном `N` и выбранном пользователем `k_bits`:
  - Визуализируем сообщение как последовательность из `N` групп бит
  - Каждая группа содержит ровно `k = log₂(I)` бита (если пользователь выбрал `k_bits ≥ k`)
  - Группы разделены цветом/разделителями

### Уведомления об ошибках:
- Если `k_bits < log₂(I)` → показываем сообщение «Недостаточно бит для кодирования всего алфавита!»
- Если `N` выходит за границы → валидация 5 ≤ N ≤ 256

### Шаг 1: Выбор из готовых алфавитов
**Интерфейс:**

  - «Русский» (I = 33)

### Шаг 2: Ввод бит на символ (`k_bits`) и проверка
**Интерфейс:**
- Input number с полем для ввода `k_bits` (1–5)
**Проверка системы:**
- Вычисляет `log₂(I)` — минимальное бита для полного кодирования алфавита
- Если пользователь выбрал `k_bits ≥ log₂(I)` → OK

**Интерфейс:**

**Интерфейс**

**Автоматическое отображение:**
- Формула расчёта: `V = N × k_bits` с подстановкой значений
- Объём в битах: `V_raw = N × k_bits`
- В байтах (с округлением вверх): `V_bytes = ceil(V_raw / 8)`
- Проверка введённого пользователем значения `V_user`

## 4️⃣ Правило округления (важно!)

**Определяем разницу между двумя подходами:**

❌ **Неправильно:** каждый символ в целых битах → `1 × 7 = 7` байт  
✅ **Правильно:** суммарное число бит округляем до полного байта  

**Пример:**
- `I = 4` ⇒ `k = log₂(4) = 2` бита на символ
- `N = 7` символов → `V_raw = 7 × 2 = 14` бит (целое число, округление не нужно!)

**Другой пример:**
- Если бы код требовал 3 бита при `I=32`, и `N=5`, то `V_raw = 15` бит ✅ (не нужно округлять)  

**Формула для представления:**
```cs
int raw_bits = N * (int)Math.Round(Math.Log(Alphabet_Size)/Math.Log(2), 0);
byte count = (raw_bits + 7) / 8; // целочисленное округление до байтов
string note = raw_bits % 8 == 0 
    ? $"Сообщение занимает {byte_count} байт ({raw_bits/8})"
    : $"Минимум {byte_count} байт для {raw_bits} бит";
```

## 7️⃣ Форматы вывода

### Для задачи Тип А:
```
Задача: Иметь I = @I, N = @N → найти V
log₂(@I) = @(BitPerChar) бит на символ
V = N × k = @N × @(BitPerChar) = @(TotalBits_Exact) бит
  = @byte_count байт (округлённо до полного байта, если %8 != 0)
```

### Для задачи Тип Б:
```
log₂(I) = k ⇒ I = 2^k
При заданной мощности алфавита @(BitPerChar) бит/символ:
I_max = 2^@(BitPerChar) = @(Math.Pow(2, BitPerChar)) символов
```

## 9️⃣ Уведомления и ошибки

**Сценарий 1: Недостаточно бит**  
Если `k_bits < log₂(I)`:
- Показываем ошибку: «Недостаточно бит для полного кодирования выбранного алфавита!»
- Предлагаем увеличить k_bits или сменить алфавит

**Сценарий 2: Валидация N**  
Если `N < 5` или `N > 256`:
- Ограничиваем input/ slider диапазоном
- Показываем подсказку о допустимом диапазоне
